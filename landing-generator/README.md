# Landing Generator

Закрытый переносимый генератор лендингов: проекты, парольный вход, чат, изолированное превью и публикация статической версии.

## Запуск

```powershell
cd landing-generator
Copy-Item config.example.json config.json
pnpm start
```

Откройте `http://127.0.0.1:4317/`. При первом запуске приложение попросит задать пароль и сохранит только его хеш в `data/store.json`.

## Конфигурация

`config.json` не добавляется в репозиторий. Пути `dataDir`, `publicDir`, адрес и порт задаются там. AI подключается опционально через `POLZA_API_KEY`, `AI_BASE_URL` и `AI_MODEL`; без ключа работает локальный безопасный демо-режим.

## Архитектурные границы

- `data/` — закрытое состояние, не публикуется веб-сервером.
- `published/` — только статические опубликованные проекты.
- секреты не хранятся в репозитории.
- превью загружается в sandboxed iframe.
- проектные slug уникальны.
